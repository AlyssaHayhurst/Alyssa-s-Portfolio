# Introduction to Giraffe Gobble!
Giraffe Gobble feature a user-controlled Giraffe character that survives by moving left and right to catch falling leaves. The leaves allow the giraffe to purchase speed boosts and move faster, but watch out! The giraffe has to simultaneously dodge falling rocks which reduce lives! If the giraffe loses all three lives, it dies! Apricots can also be caught and eaten in order to have temporary immunity boosts (meaning immunity from falling rocks).

# What does Giraffe Gobble! do?
Giraffe Gobble! is a fantastic game where players control a giraffe and help it survive as long as possible.
Catching leaves increases the player's score and allows speed upgrades!
Falling rocks must be avoided because they reduce lives (players start with 3 lives)
Apricots provide temporary immunity from rocks!
The game becomes more challenging as objects continuously fall without end!

# How to Run Giraffe Gobble!
This game uses Java Swing and was constructed on CodeHS.
Open the Giraffe Gobble! project in CodeHS to play.
Click the green **Run** button at the top of the CodeHS editor.
The game will start in a fixed 800x600 pixel game window.
Register and create your Giraffe Gobble! account, or login to your pre-existing account.
Read the instructions, and click START to play!
Use keyboard controls to move the giraffe character left and right. Be careful! Catch leaves and apricots while avoiding falling rocks!
If you lose all your lives, don't worry, you can restart (By clicking 'R' on your keyboard)! But remember to try and beat your high score, or just have fun!
To logout, hit the red LOGOUT button in the top right hand corner.

# Project Goals and Purpose
Entertainment: Giraffe Gobble! is an entertaining arcade-style game that challenges player's reaction time and decision-making skills. Players must help their giraffe survive.
Programming Goals: This project demonstrates important programming and game development concepts, through the use of event handling and user interaction (player movement and controls), collision detection, score and lives systems (scores stored through classes into text files), and power-ups incorporating Java Swing timer. This demonstrates heavy object-oriented programming with a variety of abstract classes and interfaces, as well as creative graphical user interfaces, and the use of file input/output (for user login/registration).
The overall goal was to create create a fun, creative, and enjoyable game while applying strong and consistent programming and software design skills through Java Swing. Giraffe Gobble! is a fun and interactive user-friendly game!

# Installation and Setup Instructions
Open CodeHS and run the program. This game opens in an 800x600 window for optimal user graphics. The keyboard is used to navigate the game.
